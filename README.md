# MyPicker website

The public page, [Privacy Policy](privacy.md), and [Terms of Use](terms.md) for MyPicker, published with GitHub Pages at https://spicesx.github.io/mypicker/.

Edit `privacy.md` or `terms.md`; the HTML pages render them. Plus Jakarta Sans is included under the SIL Open Font License (`fonts/OFL.txt`); marked is MIT licensed.

`glow.js` draws the app's Picker lights with WebGL 2 (a port of its Metal shader); without WebGL the page shows a still glow.
